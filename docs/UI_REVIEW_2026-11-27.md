# Review UI/UX layanan, kontak, dan footer

Sumber: skill lokal terkunci dalam `docs/SKILL_SOURCES.json`. Arahan dan alasan visual ada di `DESIGN.md`. Cakupan review: komponen yang diubah dalam rilis ini; bukan sertifikasi aksesibilitas seluruh situs.

## Keputusan

Anti Slop digunakan selama pengerjaan, mengikuti standar proyek yang diminta pemilik. UI/UX Pro Max dipakai untuk hierarki dan pemeriksaan UX; rekomendasi warna/template yang tidak sesuai ditolak. Modern Web Guidance dipakai untuk native disclosure, pengurangan informasi sekunder, tipografi judul, serta semantik/fokus footer. Header/footer tidak memakai aset hasil generasi atau data shipment palsu.

Footer memakai panel tracking dengan perbedaan permukaan, judul lebih kuat, nomor layanan yang mudah dipindai, dan navigasi dua kolom. Tidak ada daftar lima kelompok kontak yang berulang di setiap halaman. Kontak lainnya tersedia di direktori halaman Kontak. Label baru dan judul tetap dapat dikelola Operator.

## Batas pengukuran

Lighthouse/Core Web Vitals lapangan, sesi pembaca layar manual, dan perangkat ponsel fisik belum diukur. Browser lokal yang digunakan adalah Edge headless di Windows. Workflow Linux/Chromium ditambahkan untuk memeriksa checkout bersih; status aktualnya harus dibaca dari GitHub Actions setelah push. Hasil deployment dan live audit dicatat terpisah di laporan rilis, bukan diasumsikan dari build lokal.
